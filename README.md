# Drop Zone

A tiny browser battle royale. Move, shoot, build, and stay inside the storm.

## Play in GitHub Codespaces

1. Open this repository in GitHub Codespaces.
2. The dev container forwards port **8080** and starts a static server with `python3 -m http.server 8080`.
3. Open the forwarded port in the browser.

## Controls

- **WASD** move
- **Mouse** aim, **click** shoot
- **1** place a wall, **2** place a ramp
- **R** restart after a win or loss
